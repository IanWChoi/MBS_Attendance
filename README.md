# Zoom 출석 체크 자동화 도구

이 프로젝트는 Zoom에서 다운로드한 로그 파일과 수강생 명단을 기반으로 출석 처리를 자동화하는 웹 애플리케이션입니다.

Jupyter Notebook으로 구현되었던 기존 로직을 순수 HTML, CSS, JavaScript로 재구성하여, 별도의 프로그램 설치 없이 웹 브라우저에서 모든 기능을 사용할 수 있도록 만들었습니다.

---

## 주요 기능

- **느슨한 매칭**: Zoom에 표시된 이름에 `학번` 또는 `성명` 중 하나라도 포함되면 출석으로 인정합니다. 표기 흔들림은 아래 [매칭 규칙](#매칭-규칙)에서 폭넓게 흡수합니다.
- **명단 무손실**: 학번이 비어 있어도 학생을 명단에서 제외하지 않고 **이름만으로** 매칭합니다. 입력한 명단과 결과 시트의 인원수는 항상 같습니다.
- **출석 시간 기준**: 매칭된 학생의 총 체류 시간(분)이 **기준 시간(기본 90분) 이상**일 경우 '출석'으로 처리합니다. 회차별로 화면에서 조정할 수 있습니다.
- **원본 열 보존**: 명단 파일의 기존 열을 그대로 유지한 채 날짜 열을 덧붙이므로, 하나의 명단 파일에 회차를 계속 누적할 수 있습니다.
- **판정 근거 표기**: 결과에 `총 체류(분)`과 `매칭된 Zoom 이름` 열이 함께 나와, 느슨한 매칭이 엉뚱한 사람에게 붙지 않았는지 눈으로 확인할 수 있습니다.
- **다양한 파일 형식 지원**: 명단은 `.xlsx`·`.csv`, Zoom 로그는 `.csv`(쉼표/탭, UTF-8/CP949)를 자동 판별합니다.
- **자동 리포트 생성**: 처리 결과는 두 개의 시트(`출석 체크`, `확인 필요`)를 가진 엑셀 파일(`출석결과_<날짜 열 이름>.xlsx`, 예: `출석결과_4월21일.xlsx`)로 자동 생성되어 다운로드됩니다.
- **샘플 양식 제공**: 사용자가 쉽게 출석 명단을 만들 수 있도록 '성명', '학번' 순서의 샘플 엑셀 파일을 제공합니다.
- **100% 브라우저 기반**: 모든 파일 처리와 로직이 사용자의 웹 브라우저 내에서만 실행되므로, 서버로 어떠한 데이터도 전송되지 않아 안전합니다.

## 사용 방법

1.  상단의 **배포 페이지 링크**로 접속합니다.
2.  출석 명단 파일이 없다면, **[샘플 엑셀 다운로드]** 버튼을 눌러 양식을 받습니다. 양식에 맞게 수강생들의 성명과 학번을 기입하여 파일을 저장합니다.
3.  **[1. 출석 명단 파일]**에서 직접 만든 출석 명단 파일(`.xlsx` 또는 `.csv`)을 업로드합니다.
4.  **[2. Zoom 로그 파일]**에서 Zoom 회의가 끝난 후 다운로드한 참가자 로그 파일(`.csv`)을 업로드합니다.
5.  **[3. 출석을 기록할 열 이름]**에 원하는 날짜를 텍스트로 입력합니다. (예: `5월10일`)
6.  **[4. 출석 인정 최소 체류 시간]**은 기본 90분입니다. 수업이 늦게 시작했거나 짧았던 회차는 낮춰서 사용합니다.
7.  **[출석 처리 및 엑셀 생성]** 버튼을 클릭합니다.
8.  처리가 완료되면 결과 엑셀 파일이 자동으로 다운로드됩니다.
9.  결과의 **`매칭된 Zoom 이름` 열을 한 번 훑어보고**, `확인 필요` 시트에 수강생이 남아 있지 않은지 점검합니다.

> 다음 회차에는 **직전 회차 결과 파일을 그대로 명단으로 다시 올리면** 됩니다. 기존 날짜 열은 보존되고 새 날짜 열만 추가됩니다.

## 매칭 규칙

Zoom 표시 이름은 사람마다 제각각이라, 아래처럼 정규화한 뒤 비교합니다.

| 항목 | 처리 | 예시 |
| --- | --- | --- |
| 구분자 | 공백·괄호·하이픈·언더바·쉼표·점 모두 제거 | `2525419128홍길동` = `2525419128 홍길동` = `홍길동 (홍길동)` |
| 발음기호 | 라틴 문자의 성조/기호 제거 | `Nguyễn Vương Bảo Ngọc` = `NGUYEN VUONG BAO NGOC` |
| 대소문자 | 모두 대문자로 통일 | `sunhee shin` = `SUNHEE SHIN` |
| 학번 | 4자 이상 영숫자일 때만 매칭 키로 사용 | `D25401003`, `2617603003` (○) / `-`, 공백 (×) |
| 한글 이름 어순 | 성이 뒤로 간 표기도 인식 | 명단 `이정희` ↔ Zoom `정희 이` |
| 영문 이름 어순 | 모든 토큰이 순서와 무관하게 들어 있으면 인식 | 명단 `Hueppe Kathrin` ↔ Zoom `Kathrin Hueppe-2525409001` |

### 학생별 독립 합산

체류 시간은 **학생마다 자기와 매칭되는 로그를 전부 독립적으로 합산**합니다.
로그 한 건을 학생 한 명에게만 배정하면, 먼저 걸린 학생이 다른 학생의 출석을 가져가 버립니다.
(실제로 학번이 `-` 로 입력된 명단 한 줄이 하이픈 들어간 Zoom 이름을 모두 선점해, 세 명이 미출석 처리된 적이 있습니다.)

### 인코딩 자동 판별

Zoom 원본 로그는 UTF-8이지만, 엑셀에서 한 번 열었다 저장하면 CP949(EUC-KR) + 탭 구분으로 바뀝니다.
UTF-8로 읽어 글자가 깨지면 자동으로 EUC-KR로 다시 읽으므로, 어느 쪽을 올려도 동작합니다.

## 명단 작성 시 주의사항

정확도에 가장 큰 영향을 주는 것은 코드가 아니라 **명단 파일의 품질**입니다.

- **학번 칸을 `-`, `미정`, 공백 등으로 채우지 마세요.** 값이 확실하지 않으면 그냥 비워 두면 됩니다. 이름만으로 매칭합니다.
- **박사과정 등 영문자가 섞인 학번(`D25401003`)도 그대로 입력하세요.** 숫자가 아니라고 비워둘 필요 없습니다.
- **외국인 수강생은 가능하면 학번을 반드시 채우세요.** 명단은 로마자(`NGUYEN VUONG BAO NGOC`)인데 Zoom은 한글(`응우옌 부옹 바오 응옥`)로 표시하는 경우가 많아, 이름 매칭이 불가능합니다.
- 수업 시작 전 수강생에게 **Zoom 이름을 `학번 성명` 형식으로 바꾸도록** 안내하면 미매칭이 크게 줄어듭니다.

## 결과 파일 구성

**`출석 체크` 시트** — 업로드한 명단의 모든 열 + 아래 3개 열

| 열 | 설명 |
| --- | --- |
| (입력한 날짜) | 기준 시간 이상이면 `출석`, 아니면 공백 |
| `총 체류(분)` | 매칭된 모든 접속의 합계 |
| `매칭된 Zoom 이름` | 판정 근거가 된 Zoom 표시 이름 (여러 개면 ` / ` 로 연결) |

**`확인 필요` 시트** — 어떤 수강생과도 매칭되지 않은 Zoom 참가자

| 열 | 설명 |
| --- | --- |
| `Zoom 표시 이름` | 로그에 표시된 이름 |
| `총 체류 시간(분)` | 합계 체류 시간 (긴 순으로 정렬) |
| `접속 횟수` | 로그에 나타난 접속 건수 |
| `비고` | 미일치 사유 |

운영진·강사·타 과정 청강생이 여기에 섞이므로, 체류 시간이 긴 항목 위주로 확인하면 됩니다.
